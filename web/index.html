Monster Hunter Frontier

FrontierTextHandler TEXT HANDLER

Extract the game's text for translation, then put your translations back into a game-ready file.

Everything runs in this browser tab. Your game files are never uploaded.

Loading the Python engine…

1 Open a game file

Pick mhfdat.bin, mhfpac.bin, mhfinf.bin or another text file from your game's dat/ folder.

2 Translate

Type your translation under each original text. Keep markers such as {c05} and {j} where they belong. Your work is saved in this browser and included when you build in step 3.

    Download the sections you want to translate as CSV and JSON files. Fill in the target column and leave rows you are not translating empty.

    3 Build the translated file

    Add your translated CSV or JSON files, or a translation release from MHFrontier-Translation (translations-fr.json.gz, for instance). They must match the game file you opened in step 1.

      Options

      Building mhfdat.bin takes about 40 seconds, smaller files a few seconds. Replace the file in your game's dat/ folder with the download, and keep a backup of the original.
